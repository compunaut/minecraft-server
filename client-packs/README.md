# Download the client pack

Tagged releases add `epic-fight-pack-vX.Y.Z.zip` and its SHA-256 file here automatically. Download the version your server administrator specifies and import the intact ZIP into CurseForge on Windows. No Docker, Git or terminal is needed.

The folder will contain its first ZIP after the first successful version-tag release. Before then, use the build's `client-pack` Actions artifact or a ZIP shared by your administrator. Older versioned ZIPs are retained and never overwritten.
